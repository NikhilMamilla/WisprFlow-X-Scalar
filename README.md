# Haq Bolo

A voice-first scheme finder for India's informal workers. The worker talks, the app asks short follow-up questions, then tells them which government schemes to chase first and prints a sheet of what to carry.

Built for Scaler x Wispr Flow "India Runs on Voice", Round 2 (Team Abhyudaya).

## Run it

```
docker compose up
```

Then open http://localhost:3000. No `.env` file is required — the app runs fully without any LLM key. See `.env.example` for the optional `LLM_API_KEY`.
